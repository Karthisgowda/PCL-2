# AI in Education IJSRED Presentation

This repository contains a 10-slide HTML presentation for the published paper:

**The Impact of Artificial Intelligence on Education: Blending New Technology with Equal Opportunities and Responsible Use**

Authors: Ananya HG, Harsha K, Ananya Dalania, Akshay Kumar

Publication details:

- Journal: International Journal of Scientific Research and Engineering Development
- Issue: Volume 9, Issue 2, March-April 2026
- Pages: 530-536
- Paper ID: IJSRED-V9I2P83
- DOI: 10.5281/zenodo.19013856
- Published link: https://www.ijsred.com/volume9-issue2-part9.html
- Online edition: https://www.ijsred.com/mar-apr-2026.html
- Copyright form date: 12-03-2026

## View locally

Open `index.html` in a browser, or run:

```bash
npm install
npm start
```

Use the arrow keys, Page Up/Page Down, or the on-screen controls to navigate. Press `F` for fullscreen.
